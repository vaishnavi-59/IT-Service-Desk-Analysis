# IT Service Desk Ticket Analysis

## Project Overview
This project analyzes IT support tickets to understand ticket resolution, pending tickets, SLA performance, frequently reported issues, and support team productivity.

The goal is to identify operational trends and generate useful insights through data analysis and interactive dashboards.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- MySQL
- Microsoft Excel
- Power BI

## Project Objectives
1. Analyze total IT support tickets.
2. Identify resolved and pending tickets.
3. Evaluate SLA performance and SLA breaches.
4. Analyze department-wise and priority-wise ticket distribution.
5. Measure support team and agent productivity.
6. Identify monthly ticket trends.

## Dataset
- Dataset: Synthetic IT Service Desk Ticket Dataset
- Records: 3,000 tickets
- Period: January–October 2026
- Generated using Python.
- Contains ticket details, departments, issue types, priorities, status, resolution time, and SLA information.

## Project Workflow

### 1. Python – Data Cleaning and EDA
- Generated and inspected the dataset.
- Handled duplicate records and validated data.
- Performed exploratory data analysis.
- Created charts and exported analytical reports.

### 2. MySQL – Data Analysis
- Created a database and tickets table.
- Imported 3,000 cleaned records.
- Used SQL queries for ticket distribution, SLA performance, resolution time, monthly trends, and team productivity.

### 3. Microsoft Excel – Dashboard
- Imported analytical reports.
- Created KPI summaries and charts.
- Built an Excel dashboard.

### 4. Power BI – Interactive Dashboard
- Created KPI cards.
- Built ticket status, priority, SLA, and monthly trend charts.
- Added Department and Priority slicers for interactive filtering.

## Key Findings
- Total Tickets: 3,000
- Resolved Tickets: 2,084
- Pending Tickets: 916
- Resolution Rate: 69.47%

## Business Value
This analysis helps understand IT support workload, monitor ticket resolution, identify SLA issues, and evaluate support team performance.
